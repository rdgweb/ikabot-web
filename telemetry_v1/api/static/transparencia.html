Transparência

Como e por que o ikabot coleta estatísticas de uso — e o que nunca coleta.

O ikabot é open source. Para entender como o projeto é usado (versões em campo, mundos mais populares, quais recursos importam mais), cada instalação pode enviar um resumo de uso uma vez por dia para este servidor, sem nenhum dado de conta ou de jogo. Isso só acontece se o administrador do hub aceitar em Configurações → Telemetria. Enquanto ninguém decidir, nada é enviado.

O que é enviado

Sim, enviamos
  • Um identificador aleatório da instalação (UUID gerado no aceite, sem relação com você)
  • Versão do hub e dos agents; arquitetura (amd64/arm64)
  • Fuso horário configurado (ex.: America/Cuiaba)
  • Quantidades: contas do lobby, contas de jogo, nós
  • Servidor e mundo do Ikariam com o nº de contas em cada (ex.: br / 61 → 3)
  • Quantos jobs por categoria (militar, mercado…) nos últimos 30 dias
  • Seu endereço IP: o servidor o vê ao receber o resumo e o guarda (veja abaixo), e dele deriva uma localização aproximada (país, região e cidade)
Não, nunca enviamos
  • E-mail, usuário, senha, tokens ou cookies
  • Nomes de jogadores, cidades, ilhas, alianças ou qualquer dado do jogo
  • URLs, hostnames ou IPs internos do seu hub, dos seus nós ou proxies (só o IP público de onde o resumo chega)
  • Conteúdo de jobs, mensagens, relatórios ou logs

Exemplo real do envio

Este é o formato exato do que o hub envia (schema v1); o IP não vai no JSON — o servidor o observa na conexão. Dentro do hub, Configurações → Telemetria → Ver o que será enviado mostra o JSON da sua instalação.

{
  "schema": 1,
  "install_id": "3f0c9c2e-8d5e-4a58-9a3b-0c2f6f6a1d11",
  "hub_version": "0.2.80",
  "arch": "amd64",
  "timezone": "America/Cuiaba",
  "counts": { "lobby_accounts": 2, "game_accounts": 5, "nodes": 1 },
  "agents": [ { "version": "0.1.57", "nodes": 1 } ],
  "worlds": [ { "server": "br", "world": 61, "accounts": 3 },
              { "server": "br", "world": 44, "accounts": 2 } ],
  "usage_30d": [ { "category": "military", "jobs": 120 },
                 { "category": "market", "jobs": 48 } ]
}

Como tratamos o que chega

  • Endereço IP: é guardado por até 90 dias numa tabela separada e depois apagado automaticamente. Serve para estimar a localização (país, região e cidade aproximada, por uma base de geolocalização local) e reconhecer instalações repetidas. Se a localização por IP não estiver disponível, usamos o país do fuso horário. A cidade/região derivada permanece enquanto a instalação existir nos dados.
  • Uso restrito: os dados servem apenas para análise de uso do projeto pelo mantenedor. Não são vendidos, não são compartilhados com terceiros e não são usados para publicidade ou para identificar pessoas.
  • Sem logs de acesso: o servidor não mantém logs de requisições nem cabeçalhos; o IP existe apenas onde descrito acima.
  • Só o que está no schema. Qualquer campo extra é descartado antes de gravar.
  • Um resumo por instalação por dia. Enviar de novo no mesmo dia substitui o resumo anterior.
  • Retenção: IPs por 90 dias; demais dados por até 400 dias, depois apagados automaticamente.
  • Números pequenos não aparecem. Nas estatísticas públicas, grupos com menos de 5 instalações são agrupados em “outros”; IPs e cidades nunca são publicados.
  • Acesso: os dados brutos ficam num banco próprio, acessível apenas ao mantenedor do projeto.
  • Base legal: seu consentimento, dado ao ativar a telemetria (LGPD, art. 7º, I). Você pode retirá-lo a qualquer momento.

Seu controle

  • Desligar: Configurações → Telemetria → Desativar, ou defina TELEMETRY_DISABLED=true no ambiente do hub (chave-mestra: nada é enviado, mesmo com aceite anterior).
  • Apagar: ao desativar pelo hub, o hub pede a remoção de tudo que essa instalação já enviou, incluindo o IP registrado. Também dá para pedir manualmente com DELETE /v1/installs/<install_id>.
  • Auditar: o código do cliente (hub_v2/apps/telemetry) e do receptor (telemetry_v1) está no repositório do projeto.

English summary

ikabot is open source. To understand how it is used, an installation may send one usage summary per day to this server — only if the hub admin opts in (Settings → Telemetry). It contains: a random install ID, hub/agent versions, CPU architecture, the configured timezone, counts of accounts/nodes, Ikariam server/world with account counts, and job counts per category over 30 days. The server also sees and stores your public IP address, keeps it for at most 90 days in a separate table, and derives an approximate location (country, region, city) from it using a local geolocation database. It never contains credentials, e-mails, player/city names, URLs or game content. Data is used only for project usage analytics by the maintainer — never sold, shared or used for advertising. No access logs are kept, other data is deleted after 400 days, and groups smaller than 5 are folded into “other” on public stats. Disable it in Settings, or set TELEMETRY_DISABLED=true; disabling asks the server to erase everything that installation sent, including the IP. Legal basis: your consent (LGPD art. 7-I / GDPR art. 6(1)(a)). Source: the telemetry_v1 and hub_v2/apps/telemetry folders of the project repository.
