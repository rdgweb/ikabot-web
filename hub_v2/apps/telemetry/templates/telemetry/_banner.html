Estatísticas de uso: ativadas por padrão, você escolhe o que enviar

O ikabot é open source e, para entender como é usado, este hub envia uma vez por dia um resumo para {{ TELEMETRY_PUBLIC_URL }}: versão, quantidade de contas e nós, servidores/mundos do Ikariam, fuso horário e jobs por categoria. O servidor também registra o endereço IP de onde o resumo chega (por até 90 dias) para estimar a localização (país/cidade). Nunca enviamos e-mails, senhas, nomes de jogadores/cidades nem qualquer dado do jogo, e os dados só servem para análise de uso do projeto. Você pode desligar qualquer item (inclusive o IP) ou a telemetria inteira, e apagar o que já foi enviado, quando quiser. Página de transparência.
