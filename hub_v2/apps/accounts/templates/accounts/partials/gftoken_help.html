Como pegar o token
1 Entre no lobby do Ikariam com a conta
2 F12 → aba Console → cole o comando e tecle Enter
3 O token já fica copiado: cole no campo acima

Se o Chrome pedir, digite allow pasting no Console antes de colar. Sem o comando: F12 → Aplicação → Cookies → gf-token-production. O token vale como uma senha: não envie para ninguém.
