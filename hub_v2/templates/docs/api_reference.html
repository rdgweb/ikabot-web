Autenticação e alcance

Cada agent usa o token individual do seu nó nos cabeçalhos X-Agent-Token e X-Agent-Node-ID. As operações validam o nó, a conta e a organização. Um token não concede acesso a outra organização. O supervisor usa sua credencial de host.

Plano/teste encerrado impede operação; diagnóstico de conexão e consulta da autorização permanecem disponíveis para detectar regularização. Isenção e a carência contratada seguem a política do plano. Ações já enviadas ao jogo não podem ser desfeitas pelo bloqueio.
